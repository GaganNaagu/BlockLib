# BlockLib

Blockchain-Based Library Book Lending System backed by an Ethereum-compatible local Hardhat network, React + TypeScript + Vite frontend, Express + Prisma + PostgreSQL backend, and a Solidity smart contract (`Library.sol`).

See [BlockLib_PLAN.md](./BlockLib_PLAN.md) for the authoritative project specification, [docs/architecture.md](./docs/architecture.md) for the system architecture, and [docs/checklist.md](./docs/checklist.md) for implementation progress.
